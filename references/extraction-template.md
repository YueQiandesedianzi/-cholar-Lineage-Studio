# 统一提取模板

综述写作前先定义统一的证据提取口径，保证多人提取一致。

## 默认字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 研究问题 | text | 是 | 文献回答的核心问题 |
| 方法 | text | 是 | 建模/实验/计算手段 |
| 主要发现 | text | 是 | 含定量结果或效应量 |
| 结论 | text | 否 | 作者结论 |
| 局限性 | text | 否 | 作者自述或证据边界 |

## 可扩展字段类型

`text` / `number` / `enum` / `scale` / `excerpt`

- `number`：样本量、R²、RMSE、温度等定量值。
- `enum`：研究设计（RCT/队列/横断面）、方法类别（MD/DFT/ML）。
- `scale`：1–5 证据强度评分。
- `excerpt`：强制要求逐字摘录的字段。

## 使用约定

- 字段可按学科自定义，但**必填字段缺失时提取结果须标记为"不完整"**。
- 每条卡片的核心字段（论断 / 摘录 / 定位 / 类型 / 置信度 / 状态）不得省略，见 `evidence-card-spec.md`。
- 模板变更不覆盖历史提取记录（版本化）。
