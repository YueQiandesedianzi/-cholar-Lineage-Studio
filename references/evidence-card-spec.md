# 证据卡片规范

## 字段

| 字段 | 说明 |
|---|---|
| card_id | 稳定编号（C01、C02 …） |
| 来源文献 | 标题 / 第一作者 / 年份 / DOI |
| 领域标签 | 如：MD、DFT、ML、膜分离 |
| 证据类型 | 数据 / 结果 / 方法 / 结论 / 局限性 / 引语 |
| 论断（claim） | 该卡片陈述的具体观点或发现 |
| 原文摘录（excerpt） | 来源文本的逐字子串 |
| 定位（locator） | 页码 / 段落 / 图表，或如实标注"摘要" |
| 置信度 | 0–1 |
| 核验状态 | 待核验 / 已核验 / 已驳回 / 需修订 |

## 核验状态机

```
待核验 → 已核验
       → 已驳回
       → 需修订（人工修正后 → 已核验）
```

- 状态流转须记录操作人与时间。
- 未核验卡片不可作为"已核验证据"引用。

## 逐字摘录硬约束

- 摘录必须能在来源文本中找到（子串或规范化模糊匹配）。
- AI 概括与逐字摘录分离：概括只是辅助阅读，**不算证据**。
- 定位缺失或摘录不匹配 → 标记"未通过原文校验"，**禁止进入已核验**。
- 表格/图表中的结构化数值单独走人工核对通道，标记为"结构化数值"。

## 修订记录

修订须保留 diff：

```
- AI 原始论断：……（过度夸大/遗漏限定）
- 人工修正论断：……（改回证据支持的强度）
- 理由：……
```

## 证据强度校准（示例）

- 多篇独立实验/物理模拟一致 → 可写"表明/证实"。
- 单一 ML 预测或小数据集 → 写"初步表明/提示"。
