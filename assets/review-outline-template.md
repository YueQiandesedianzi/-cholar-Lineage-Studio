# 综述框架模板

（思路图据此展开，可按主题自定义章节）

## 通用结构

1. **引言** —— 背景 / 研究问题 / 综述范围与意义
2. **方法总览** —— 技术路线分类（如 MD·MC / DFT·VEH / ML·QSPR / 多尺度）
3. **[主题 A]** —— 关键方法与发现
4. **[主题 B]**
5. **[主题 C]**
6. **讨论** —— 共识 / 分歧 / 证据强度 / 挑战
7. **结论与展望**

## 思路图绘制要点

- 中心主题 → 各章节 → 每节 3–4 个要点。
- 颜色区分领域（如：MD 橙 / DFT 绿 / ML 蓝 / 膜 紫 / 框架性章节灰）。
- 每节要点 = 该节核心论断（须与证据卡片对应）。

## 分工标注

在综述正文开头标注"分工映射"：

```
§1–§3 作者甲；§4–§6 作者乙；§7–§8 主编（合并+统一）。
```

## 自定义规则

- 章节可增删、重命名、调整顺序、调整层级。
- 章节与负责人绑定，负责人的分支对应其章节。
