# 证据卡片 Markdown 模板

每条卡片按下列格式记录（复制后填写）：

```markdown
### Cxx · 第一作者 et al. 年份, 期刊
- **证据类型**：主要发现 / 方法 / 结论 / 数据 / 局限性
- **论断**：……
- **原文摘录**："……"（来源文本的逐字子串）
- **定位**：摘要 / 页码 / 段落 / 图表
- **置信度**：0.xx
- **核验**：✅ 通过 / ✏️ 修订 / ❌ 驳回
```

## 核验记录（对修订/驳回卡片追加）

```markdown
### Rx · Cxx 修订
- **AI 原始论断**：……
- **人工修正论断**：……
- **理由**：……

### Rx · Cxx 驳回
- **驳回理由**：……
```

## 汇总表（放在证据库末尾）

```markdown
## 核验统计
通过 X · 修订 Y · 驳回 Z · 共 N 条
```
